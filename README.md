# Mini Quiz Game in Python 🧠

A dynamic, interactive command-line quiz game built in Python that tests general knowledge, calculates scores in real time, and allows continuous replay.

## 🚀 Features & Mechanics
- **Interactive Gameplay:** Asks for the player's name and provides personalized feedback throughout the quiz.
- **Score Tracking:** Tracks score dynamically, awarding +10 points for each correct answer (up to 40 points).
- **Case-Insensitive Input:** Uses `.upper()` method so answers work seamlessly in both uppercase and lowercase (`b` or `B`).
- **Game Loop & Replay:** Built with a `while True` loop and `break` condition to allow players to restart the game anytime.
- **Dynamic End Ratings:** Displays customized completion messages based on final score (*Perfect score!*, *Good job!*, or *Keep practicing!*).

## 🛠️ Concepts & Technologies Used
- **Language:** Python 3
- **Control Flow:** `while` loops, `if / elif / else` conditions, `break`
- **String Methods:** `.upper()` for input sanitization
- **Operators:** Addition assignment (`+=`) for scoring
